# vc-x1 config file

vc-x1 configuration, the work side. The `toml` fences, concatenated in document order, form
the config ([vc-config-test.md](vc-config-test.md) is the model rendering). Per-key
documentation: [vc-config-design.md](notes/vc-config-design.md).

The two repos
- work [[1]]
- bot [[2]]
```toml
[repos]
work = "."
bot = ".claude"
```
